**Level Lens** is a macOS Safari extension that brings instant salary transparency to the job search process. It automatically detects when you're browsing a career page or job board and injects a native-feeling sidebar containing real-time salary data from Levels.fyi.

### 🚀 Key Features

- **Automatic Detection:** Intelligent URL and page parsing detects career sites for thousands of companies.
- **Native Safari Sidebar:** A glassmorphic, dark-mode sidebar that feels like a native part of the browser.
- **Intelligent Matching:** Uses local heuristics and an Apple Intelligence fallback to resolve company names from domain slugs.
- **Private by Design:** Matching happens on-device; no browsing history is ever transmitted to external servers.
- **Comparison Mode:** Side-by-side salary comparison against a preferred company.

![Level Lens Sidebar](/images/level-lens-sidebar.png)

### 🛠 Technical Stack

Built with a **SwiftUI** host app and a **Safari Web Extension (Manifest V3)**, Level Lens leverages **Apple Intelligence** foundation models for fallback company resolution. The entire experience is designed to feel like a premium, native extension of the macOS ecosystem.
